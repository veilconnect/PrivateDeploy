PrivateDeploy 다운로드

최신 공개 빌드는 2026년 6월 30일 릴리스된 v2.0.14입니다. 이 바이너리는 preview 빌드로 사용하고 실행 전 checksums를 확인하세요.

릴리스 노트 Checksums

플랫폼 선택

이 릴리스는 아래의 체크섬이 제공되는 데스크톱 압축 파일만 배포합니다.

Windows

대부분의 최신 PC는 amd64를 사용합니다. arm64는 Windows on Arm 장치용입니다.

Linux

현재 Linux 산출물은 amd64 압축 파일입니다. DEB/RPM 패키지는 릴리스 게이트로 남아 있습니다.

PrivateDeploy-linux-amd64.zip6.1 MB
다운로드

Android

이 릴리스 워크플로는 Android 패키지를 만들지 않습니다. 모바일 앱은 소스에서 빌드하세요.

빌드 필요

iOS

iOS는 아직 바로 사용할 수 있는 공개 다운로드가 아닙니다. VPNCore.framework, App Group, Network Extension 권한이 필요합니다.
